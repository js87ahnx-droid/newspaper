# 소스 실측·공식 API 조사 (S3, 2026-10-15)

- 실측 도구: `tools/probe_feeds.py`(후보 URL), `tools/check_sources.py`(sources.yaml 의 켜진 피드 재점검)
- 측정 시각: 2026-10-15 오후 KST, 요청 헤더는 일반 RSS 리더 수준의 User-Agent
- "요약"은 RSS가 주는 30자 이상의 리드. 본문 아님.

### Google 뉴스 대체 경로의 한계 (승인 전 확인 사항)
- 리드가 없다(요약 칸에 제목만 들어 있음) → 지면에는 제목·매체·링크만 표시, 입장 비교의 특징 단어도 제목에서만 뽑힘
- 링크가 Google 뉴스 경유 주소다(누르면 원문으로 이동)
- 매체 메인 노출 여부를 알 수 없다 → 주목도의 "메인 노출" 항목은 0으로 계산
- Google의 검색 결과 순서에 따라 일부 기사가 빠질 수 있다

## 2. 수집 시간창을 한 번의 수집으로 덮지 못하는 문제 (설계 변경 필요)

피드는 최근 N건만 담는다. 이번 측정에서 담긴 시간 폭이 시간창(11시간)보다 짧은 피드가 16개였다.

| 피드 | 담긴 시간 폭 |
|---|---|
| NHK 주요 | 2.4h |
| 경향 종합 / 한경 전체 | 2.9h / 3.0h |
| 동아 종합 / 연합 전체 | 3.9h / 3.9h |
| Fox 최신 / Al Jazeera | 4.7h / 6.3h |
| 그 밖 9개 | 5.3~10.5h |

(낮 시간 측정이라 밤에는 기사가 적어 폭이 더 길겠지만, 06:00 한 번만 수집하면 전날 저녁 기사를 놓칠 수 있다.)

→ **S4·S10 설계 변경:** 시간창 안에서 여러 번(예: 19:30, 22:00, 00:30, 03:00, 05:50 KST) 수집해 누적하고 06:10에 발행한다. 누적분은 Actions 캐시에 보관한다(제목·리드·링크만, 본문 없음). 공개 저장소의 Actions 실행 시간은 무료·무제한이다.

## 3. 공식 API 조사 (본문 제공)

| 매체 | 공식 API | 본문 범위 | 이용 조건 | 키·비용 |
|---|---|---|---|---|
| **Guardian** | Open Platform Content API | **전문** (`show-fields=body`) | 무료 키는 비상업 전용, 초당 12회·하루 5,000회, 출처 표기 | 즉시 발급, 무료 |
| New York Times | Developer APIs (Top Stories, Article Search) | 제목·초록·첫 문단(전문 없음) | 비상업 무료, 호출 한도 있음(자료마다 다름 — 발급 시 확인) | 무료 가입 |
| AP | Media API | 전문 | 기업 라이선스 계약 | 유료, 가격 비공개 |
| Reuters | Reuters Connect | 전문 | 기업용 | 유료, 견적제 |
| WSJ | Dow Jones Developer Platform·Factiva | 전문 | 기업용 | 유료 |
| Nikkei Asia | S&P Global 경유 라이선스 | 전문 | 기업용 | 유료 |
| SCMP | 기업 라이선스 | 전문 | 기업용 | 유료 |
| Japan Times | 없음 (재사용은 사전 허가·이용료) | - | - | - |
| CNN, Fox, BBC, Al Jazeera, NHK | 공개 뉴스 API 확인 안 됨 | - | - | - |
| Global Times | 미확인 | - | - | - |
| 국내 10곳 | 매체 자체 공개 API 확인 안 됨(미확인) | - | - | - |
| (국내 공동) 빅카인즈 | Open API 있으나 확인된 이용처는 협약 기관·공모전 | 웹은 본문 200자까지, 전문은 뉴스토어 유료 | 개인 발급 여부 미확인 — 재단 문의 필요 | 미확인 |

조사 한계: Guardian·NYT·AP·Reuters 공식 문서 도메인은 조사 환경에서 직접 열리지 않아 2차 자료로 교차 확인함. 키 발급 시 공식 약관을 다시 확인한다.

**결론:** 무료 공식 API로 개인 열람용 본문을 받을 수 있는 곳은 **Guardian 한 곳**. NYT는 초록·첫 문단까지(리드 보강용). 나머지는 원문 링크 + Safari 읽기 모드가 기본 경로.
